# FAQ-бот для репетиции HackAlem AI (Трек 03)

Простой консольный бот, отвечающий на 5 основных вопросов о репетиции хакатона на основе ключевых слов без использования RAG и внешних LLM-библиотек.

## Структура проекта
* `faq.txt` — база знаний (5 пар ключевые слова | ответ).
* `bot.py` — скрипт консольного чата.

## Требования
* Python 3.7 или выше (внешние зависимости не требуются).
